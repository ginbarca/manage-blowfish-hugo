# Support

Use the channel that best matches your request:

- **Bug in the skill or audit script:** open a bug report.
- **New Blowfish/Hugo behavior:** open an upstream update issue.
- **New capability:** open a feature request.
- **How to use Blowfish in your own project:** start a GitHub Discussion when
  discussions are enabled.
- **Security concern:** follow [SECURITY.md](SECURITY.md).

Include your Hugo version, Blowfish version, installation method, operating
system, relevant configuration paths, the exact command, and sanitized output.
Never post credentials or private repository content.
